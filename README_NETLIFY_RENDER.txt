SOTSBA — Frontend conectado ao backend Render

Backend configurado por padrão:
https://sotsba-backend.onrender.com

Publicação no Netlify:
1. Abra o site do SOTSBA no Netlify.
2. Em Production deploys, use o upload de arquivos/pasta.
3. Envie o conteúdo da pasta web deste pacote (index.html e _redirects).
4. Aguarde o deploy ficar Published.

O frontend também permite sobrescrever a API pelo localStorage usando a chave SOTSBA_API_URL.
