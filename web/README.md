# SOTSBA Web conectado ao Backend

Para Netlify, publique esta pasta `web` como site estático.
A URL da API pode ser definida no navegador antes do login pelo console:
`localStorage.setItem('SOTSBA_API_URL','https://sua-api.com')`
e recarregue.

Para uma versão comercial, configure a URL da API como variável de build e use HTTPS.
